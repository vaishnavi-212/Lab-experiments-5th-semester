## Key Concepts

### Virtualization

Virtualization allows physical computing resources to be divided into isolated virtual environments called virtual machines.

### Hypervisors

A hypervisor is a software or firmware layer that creates and manages virtual machines.

- **Type-1 Hypervisor:** Runs directly on physical hardware.
- **Type-2 Hypervisor:** Runs on top of a host operating system.

### Virtual Machines

A virtual machine is a software-based computer that provides virtual CPU, memory, storage, and networking resources to a guest operating system.

## Performance Analysis

Virtualized environments can be evaluated using metrics such as:

- Execution Time
- CPU Throughput
- Events Per Second
- Latency
- Memory Usage
- CPU Usage
